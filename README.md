# Ulanzi TC002 Pixel Studio

[English](README.en.md) | 简体中文

把 Ulanzi TC002 像素时钟（52×16 LED）变成一个多频道内容工作台：行情、通知、计时器、
像素动画、画板创作、官方社区素材，再加一个完整的音乐歌词播放器。所有内容都在浏览器里
编排，由本机 Bun 服务渲染成像素帧并推送到时钟。

![Ulanzi TC002 多频道内容工作室控制台](docs/images/tc002-control-panel.png)

## 能做什么

**频道 = 时钟上的一个 Custom App**，用 TC002 旋钮直接切换；一个频道里放多项内容时，
自动合成按序播放的轮播。

| 分类 | 内容 |
| --- | --- |
| 市场 | 内置 BTC、黄金、AAPL 等 10 个资产；可免 API key 搜索添加任意数字货币、股票 / ETF、汇率和贵金属 |
| 工具 | 通知板（含免 key 的 Webhook 入口，curl / iOS 快捷指令 / Home Assistant 一个 POST 上屏）、计时柱、番茄钟、倒数日 |
| 视觉 | 兰顿蚂蚁、鱼缸、火焰、翻页钟、流光时钟、数字雨时钟、走迷宫、像素宠物、落沙、星空穿梭、生命游戏、烟花、彩虹猫、灯牌（自定义文案与灯色）、天气粒子、大字天气钟、取景框钟（六套配色，含三套只点亮字迹的夜间低亮）、日出日落色温钟（天气类按地名搜索定位，免填坐标） |
| 创作 | 52×16 画板（画笔、像素文字、图片像素化——框出一块直接铺满整屏，可开直播上屏 + 扫码协作涂鸦）；素材库导入 Ulanzi 官方社区素材（PNG / GIF）或本地视频（ffmpeg 转 52×16 像素动画） |

控制台右上角可直接读写时钟的亮度、音量、时区等常规设置；「设备信息」页显示 SN、SSID、
IP、MAC 与固件版本，时钟换了 IP 也能在这里直接改，立即生效、重启后仍然有效，不用重装。
跑 ZOS 时同一个对话框换成 ZOS 真正提供的那些：音量、亮度、蓝牙配网，以及 Wi-Fi、IP、
电量、运行时长、空闲内存与固件驻留——官方固件才有的字段不会留成空行。
手机浏览器打开有专门的触控布局，支持添加到主屏幕；能装成应用的浏览器会在控制台左下角
收到一条安装提示（Safari 与 iOS 改说手动步骤），装不上的地方不打扰。

## 音乐歌词播放器

![音乐工作台：网易云 / Spotify 双音源切换、带封面的曲目列表、播放控制台与 52×16 实时像素预览](docs/images/tc002-music-studio.png)

顶部「音乐」是一个完整的音乐工作台：**网易云音乐**与 **Spotify** 两个音源随时切换，
搜索、歌单、专辑封面、逐行歌词（含翻译）和 52×16 像素歌词实时预览是共用的，四种显示
形式 × 四套配色随意组合。

歌词高亮是**卡拉 OK 式**的：网易云约两成曲目带逐字时间（`yrc`），高亮就按每个字
实际唱的时长走；没有逐字时间的按演唱速率估算句尾，并在歌词轨上标「估算」。关键是
**一句的结束是唱完的那一刻，不是下一句开始的那一刻**——段落最后一句后面往往跟着十几秒
伴奏，把伴奏算进去，高亮就会在歌手早已停下之后还在慢慢爬（见
[ADR 0008](docs/adr/0008-word-level-lyric-timing.md)）。

- **网易云**：扫码登录，TC002 自己下载音频并用扬声器播放。
- **Spotify**：走官方 Spotify Connect——播放发生在你选中的设备（手机、桌面客户端、
  音箱）上，工作台和时钟都是遥控器加歌词屏；在手机上换一首歌，两秒内自动跟随。需要
  你在开发者后台自建一个免费应用，步骤见[技术参考](docs/reference.md#音乐)。

歌词上屏有两条路径：

- **设备同屏**：不刷机，把歌词帧推到官方固件显示，声音由浏览器播放。
- **原生音乐固件**：网页一键侧载仓库自带的 C++ 播放器——真机扬声器出声、歌词直驱
  LED、与网页双向实时同步。侧载只进设备内存，断电或一键恢复即回到官方固件，flash
  从不被写入。

## 像素游戏厅与游戏固件

顶部「游戏」是一个像素游戏厅：**时间打砖块、像素小鸟、贪吃蛇、双人 Pong、像素赛车、
太空射击、俄罗斯方块**七款都在浏览器里直接玩（触控 / 鼠标 / 键盘），打开「上屏」后画面
以约 25fps 实时同步到时钟——不刷机，时钟就是第二块屏。双人 Pong 可以扫码把手机变成
第二个手柄。后三款是先给固件旋钮写的、再移植回网页，两边的模拟逐字节一致。

想脱离浏览器、用时钟自己的旋钮和按键玩，就侧载仓库自带的**游戏固件**：开机动画、
卡带式游戏菜单、设备信息页（电量 / USB / 版本 / IP，旋钮实时调音量），同样七款游戏配
8-bit 音效。侧载方式与音乐固件完全相同：只进设备内存、断电或一键恢复即回到官方固件，
flash 从不被写入。

## VIBE（VIBE）

把 Claude Code、Codex 等 AI 编码代理的额度搬上像素屏。它是 **ZOS 上的独立 App**，旋钮主菜单里
与「音乐」「游戏」同级：进去第一页是两个代理并排的总览，之后每个代理一页（指标、进度条与重置
倒计时），旋钮翻页、按下切「已用/剩余」、长按返回。做成 App 而不是频道，是因为频道只是一段
定时重拉的动画——没有输入，也接不了推送，而 VIBE 之后要联动本机 vibe coding 的实时状态
（见 [ADR 0011](docs/adr/0011-vibe-is-a-firmware-app.md)）。

数值是服务自己采的——读各家 CLI 已经留在这台 Mac 上的登录，直接问各家的用量接口，不用另装
什么；一家都没登录时屏上如实写「未登录」而不是编一个数（见
[ADR 0010](docs/adr/0010-vibe-native-usage-collection.md)）。

控制台顶部的 **VIBE** 标签页列出四个代理（Claude、Codex、OpenCode、Grok）及其指标，每个代理
最多星标两项（上屏显示的就是它们），带两页 52×16 预览，并能一键让时钟跳到这个 App。四家都借
各自 CLI 已经留在本机的登录，不需要填任何 API key。

## ZOS 系统固件

前两套固件是「侧载进去玩一会儿」，**ZOS**（`device/tc002-os/`）是整机替换：它顶掉官方
app，自己就是这台设备的系统。开机是一段 2.5 秒的 ZOS 字标动画，然后进入旋钮主菜单——
**音乐 / 游戏 / 轮播 / VIBE / 设置**，一页一项、全屏显示（52×16 上放不下列表：12 像素中文
格子横着只排得下四个，刚够一个词，再挤进邻项就是三行都看不清）。旋钮翻页、按下进入、长按
返回，每一层都一样；五个入口共用四种进场动画（轮播像 CRT 开机、音乐和 VIBE 都是均衡器升起、
游戏像卡带插入、设置像抽屉落下），退出就是同一段动画倒放。侧键短按调音量、长按调亮度，都会弹一条会自己消失的横条。

- **轮播**下面是控制台里的各个频道，每一页**就是**那个频道本身——没有图标也没有名字，
  名字只在帧还没下载完时出现；按下暂停 / 继续。
- **游戏**下面是与游戏固件同一批引擎的七款游戏，一款一张卡片，各有自己的 12×12 动态图标
  和合成音效（方波 / 三角波 / 噪声扫频，不带 wav，也就不用拖进 ffmpeg）。
- **音乐**显示控制台正在放什么（曲名、歌手、当前歌词、进度），旋钮上下曲、按下播放暂停。
- **设置**逐行显示网络、IP、控制台地址、音量、亮度、MAC、配网地址与运行时长。

**数据方向是反的：设备主动拉。** 替换官方 app 等于删掉它的 `POST /api/custom` 接收端，
所以 ZOS 自己长轮询控制台，频道帧、菜单、当前曲目全靠它拉；控制台从不向设备开连接。
设备同时把合成好的画面按 10fps 回传，控制台因此能看到面板上真正显示的东西。

侧载与另外两套固件同一条路：只进内存，断电即回官方固件，flash 从不被写入。ZOS 多一步——
包里放一个 `host` 文件写上控制台地址，设备靠它找到服务；没有这个文件固件照样跑，只是
没有频道也没有镜像。自带的配网页面已经能列出扫到的网络并接受提交，但**真正切换网络的
那一半默认是锁死的**（详见[技术参考](docs/reference.md#zos-系统固件tc002-os)）。

## 快速安装

需要 [Bun](https://bun.sh)（`mise.toml` 已固定 1.3.14，用 mise 则 `mise install` 即可）：

```bash
bun install
CLOCK_HOST=TC002_IP bun start        # TC002_IP 换成时钟的局域网 IP 或主机名
```

然后打开 `http://127.0.0.1:43820/`。安装为常驻服务（二选一）：

```bash
bash scripts/install.sh --host TC002_IP          # macOS LaunchAgent
bash scripts/install-docker.sh --host TC002_IP   # Docker Compose
```
